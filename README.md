# Student Portfolio Website

A modern, responsive personal portfolio built with **HTML, CSS, and JavaScript**.  
This project showcases my profile, skills, projects, and contact information in a clean and professional layout.

---

## 🚀 Features
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices.
- **Hero Section with Typing Effect**: Dynamic introduction that animates text like real typing.
- **Profile Section**: Circular profile picture with hover effects and a **Download Resume** button.
- **Skills Section**: Animated progress bars that reveal proficiency levels on scroll.
- **Projects Section**: Interactive project cards with hover lift and scroll reveal animations.
- **Contact Form**: Popup modal confirmation instead of basic alerts for a polished user experience.
- **Dark/Light Theme Toggle**: Visitors can switch between themes dynamically.
- **Scroll Reveal Animations**: Smooth fade-in effects for About, Skills, and Projects sections.

---

portfolio1/

│── image.jpg       # Your profile picture


---

## ⚙️ Setup Instructions
1. Clone or download this repository.
2. Place your **profile picture** as `profile.jpg` in the project folder.
3. Place your **resume file** as `resume.pdf` in the project folder.
4. Open `index.html` in any browser to view your portfolio.
